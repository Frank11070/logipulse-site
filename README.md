# LogiPulse — 物流媒合平台原型

「物流配 LogiMatch」是一個 Uber 式的物流媒合平台概念原型：物流需求方與物流業者透過篩選條件（送達時間、價格、評價、最近路線）自助媒合。

## 線上展示

發布後的網址：`https://<你的帳號>.github.io/logipulse-site/`

## 功能

- **即時媒合**：填寫取件／送達地、包裹大小、時間，依綜合分數推薦附近物流車
- **全台脈動**：真實台灣行政區地圖 + 3,500 台物流車即時模擬
- **企業排行**：各物流企業依好評數／平均評價／成交件數排名
- **評論**：配送評分與留言
- **多語言**：繁體中文／English／日本語／한국어／Tiếng Việt（非繁中語言的縣市區名依中華郵政英譯）
- **跑馬燈**：模擬交通、天氣、系統、警廣等即時資訊（預留串接公路局／警廣／氣象 API）

## 技術說明

目前為**純前端原型**，所有後端行為以 `svc*` 函式用假資料模擬，方便日後替換為真實 API。
規劃中的正式架構：ASP.NET Core Web API + EF Core + PostgreSQL/SQL Server + Angular + SignalR。

> 注意：此為概念原型，資料皆為模擬，非真實物流服務。
